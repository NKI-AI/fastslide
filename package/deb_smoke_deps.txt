# Packages the deb smoke test (package/smoke_deb.sh) installs alongside the
# FastSlide debs because a stock Ubuntu 24.04 system lacks them.
# libfastslide-dev depends on libfmt-dev, because the public C++ headers
# include <fmt/core.h>.
#
# smoke_deb.sh downloads these over HTTPS and checks them against the SHA-256
# below, then installs everything with dpkg, so no apt mirror is involved. On
# the hosted runners of late 2026, `apt-get update` hangs.

# fmt 9.1.0+ds1-2 and has no updates for it. If the debs gain a dependency

# package here.
#
